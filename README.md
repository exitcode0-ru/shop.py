# shop-tracker

Учебный проект на Python — трекер покупок.

## Что умеет
- Добавляет покупки (название, количество, цена) с проверками ввода
- Считает общую сумму, количество единиц и средние значения
- Находит самую дорогую и самую дешёвую покупку
- Ищет товар по точному названию

## Как запустить
1. Установить Python 3
2. В терминале: `py shop.py`
